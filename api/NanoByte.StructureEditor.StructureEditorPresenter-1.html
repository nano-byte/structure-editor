Toolkit-neutral logic for an editor for hierarchical structures. Used by GUI frontends to implement IStructureEditor<T>.

public class StructureEditorPresenter<T> where T : class

Type Parameters

T

The type of object to edit.

Inheritance
object
StructureEditorPresenter<T>

Remarks

Holds the descriptions of the structure, the object being edited and the current selection. The frontend is responsible for displaying GetRootNodes()/GetNodes(object?) as a tree, reporting the selected node via Select(Node?, out bool, out bool) and rebuilding the tree when StructureChanged is raised.
